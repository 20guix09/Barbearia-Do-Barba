# Barbearia do Barba

Site estático personalizado, com logo original e quatro fotografias reais publicadas no perfil oficial e em colaborações exibidas nele. Sem dependências de execução ou serviços pagos adicionais.

## Atualizar conteúdo

Edite `site.config.json` para alterar contatos, endereço, equipe, serviços, valores e fotografias. Execute `node build.mjs` para atualizar `dist/index.html`. Publique a pasta `dist` em uma hospedagem estática. O layout está em `dist/styles.css`; os controles estão em `dist/app.js`. O HTML-base está em `template.html`.
